### approach

I build blockchain products around **real-world problems**.

My work spans smart contracts, decentralized applications, DeFi, stablecoin payments, NFT systems, blockchain verification, provenance and real-world asset tokenization.

I approach each project from the product outward: understand the problem, design the architecture, build the blockchain layer, integrate the application and test the system before deployment.

### currently

Building and refining practical blockchain systems across **payments, DeFi, digital assets, verification and enterprise applications**.

I'm particularly interested in bringing blockchain infrastructure into existing businesses rather than treating Web3 as an isolated product category.
